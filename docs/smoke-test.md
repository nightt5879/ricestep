# 桌面陪伴版手动验收

以下是后续版本可重复使用的完整手动检查清单，不代表每一项均已在真机单独执行。用户已确认角色显示、菜单控制，以及新版煮饭和领取米饭正常；其余测试层级见[verification.md](verification.md)。

1. 首页出现“肥鱼陪工记”、鲸鱼娘、米饭库存及喂饭／专注／煮饭／收藏。菜单单击切换、双击确认；双击间隔小于320ms，长按保留系统操作。
2. 选中喂饭并双击：未饱且有米饭时扣1碗，出现吃饭姿态；饱腹或无米饭时不扣库存。检查短音效与可用时的语音反馈。
3. 专注从25:00开始；暂停后计时停止，回主页仍可查看进行中的剩余时间。提前结束须确认且不发奖励。完整完成获得1碗饭和一次收藏，不重复领奖。
4. 进入煮饭并双击开始，等指针移动后单击起锅。金色区域应显示完美白米饭、奖励2碗并发现收藏；绿色区域奖励1碗。其他位置或一直不按产生夹生／锅巴，不扣已有米饭。
5. 检查开始后的350ms防连按，以及结果出现后的500ms保护：开局双击的余击不会立即停锅，起锅后的余击不会开下一局。结果页仍是单击切换、双击确认“再来／回家”。
6. 专注运行时煮饭应提示先暂停。暂停专注后可以做饭，做完回去继续，小游戏期间不累计专注时间。
7. 收藏页单击翻看六件物品、双击回家；新收藏应在主页两侧出现，重复发现不增加种类。喂饭和发现动画期间也检查界面完整性。
8. 操作后等至少10秒再重载：米饭、收藏、完成次数应保留，进行中的专注恢复为暂停；进行中的煮饭取消且不发奖励。取消专注后重载不得显示成已完成。
9. 设备校时后与手机计时比较一段专注倒计时；大于5秒的系统时间跳变不补算。喂饱后待机超过5分钟再重载，消化后的饱腹值应保存。

存档有效期最多30天；未校时或保存失败会提示重试。当前构建无步数入口和手机同步，不需要健康权限。不要将旧版显示确认或桌面模拟测试当成新版实机验收。
