# 基础版手动验收

环境初始化阶段的按键计数示例已被“肥鱼开饭”替换。现在用以下流程检查物理设备，自动测试的范围见 verification.md。

1. 上板后出现“肥鱼开饭”、鲸鱼娘、米饭库存，以及喂饭／专注／散步／背包四项。
2. 选中喂饭时双击功能键，应扣一碗饭并出现吃饭姿态。短音效／TTS应在可用时播放；网络或系统播报忙时不应妨碍游戏操作。
3. 单击切到专注，双击进入，再双击开始。计时应从25:00递减；暂停时停止；提前结束需要确认且不发饭。
4. 单击与双击要区分：两次点击间隔需小于320ms。长按仍是系统操作。
5. 进入散步。未授权／未同步时显示等待，不显示假步数，也不允许开始。接好手机数据后按 phone-steps.md 做真实基线与增量检查。
6. 散步中离开Wi-Fi保持会话，可以回主页喂饭或查看背包；回家同步后结算完整增量。断网时结束会先确认“只结算已同步步数”，确认后未同步部分不计入本次。散步没有暂停按钮，出发和结束时分别同步手机。
7. 背包单击轮看六种纪念品、双击回家。
8. 操作后等待至少10秒，让存档完成，再重新上传同一应用路径。米饭和收藏应恢复；进行中的专注恢复为暂停。已保存起点的散步应在收到新的真实累计值后补算增量；没有起点的旧存档保持暂停，继续时重新建立起点。开发板重启后需要重新上传调试脚本。
9. 取消专注后重载，页面仍应显示未完成状态。喂饱后待机超过5分钟再重载，已经消化的饱腹值应保存，不会一直卡在满腹。

库存和收藏的存档期限受SDK限制，当前最多30天；暂未校时或保存失败会在界面提示重试。
