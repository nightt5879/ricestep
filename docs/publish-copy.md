# 肥鱼饭搭子发布文案

## 标题

【参赛作品】肥鱼饭搭子：你负责忙，她负责等饭

## 文案

我的参赛作品《肥鱼饭搭子》：一个基于 Arcs Mini3 的桌面陪伴与煮饭小游戏。🍚

把爱吃白饭的大肥鱼养在桌上：你专注做事，她陪你等开饭；看准火候煮一锅，攒米饭喂她，解锁小收藏。饭烧糊了也没关系，她还会记得上一锅，下一次认真盯锅。

作品此前已经成功部署到 Mini3，角色显示、按键交互、煮饭和米饭奖励都做过实机验证。原本准备录制实机参赛演示，但这次正式拍摄时设备一直无法完成配网，因此改用桌面模拟器展示已经实现的交互，把这个 idea 和作品呈现出来。视频中的声音为后期配音。

项目源码与视频工程已公开：https://github.com/nightt5879/ricestep
欢迎交流，也希望这只蠢萌的小饭搭子能给忙碌的桌面添一点陪伴。

本片为模拟演示，非实机拍摄；社区二创，非 DeepSeek 官方产品。
