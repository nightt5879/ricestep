# 肥鱼饭搭子 · 参赛介绍片

模式：自主自由创作。用户明确说“直接无实机演示来一个视频介绍”，不再要求设备操作或中途确认。

用途：抖音竖屏参赛作品介绍，1080×1920、30 fps、41.333 秒（1240 帧）。受众是普通观众；重点是能看懂做饭—喂饭—陪伴的小互动。此前已在 Mini3 实机验证，本次录制遇到配网问题后使用模拟器；配网经过仅在发布正文解释。

## 产品与执行决定

| 要求 | 执行 |
|---|---|
| 无实机 | 全片常驻“模拟画面 · 非实机拍摄”；只用官方 SDK 对现有 Lua 绘制的截图 |
| 已有功能 | 煮饭命中、自动米饭奖励、喂饭、烧糊、上一锅记忆、六种表情 |
| 不继续研发 | 不改 app/；不显示实验运动页，不宣称离线声音或动作识别 |
| 数据 | 新建隔离模拟状态，初始 3 碗，完美烹饪得 2 碗后喂一次变 4 碗；不读写真实存档 |
| 声音 | 同六句 hello/perfect/feed/burnt/remember_burnt/focus_start，使用 FeiyuVoice-CosyVoice3 的 cute/F6 声线本机合成；只用于视频，应用原十四句不变；注明 AI 配音 |
| 省事交片 | 自主做完本机导出、抽帧检查、独立复核，用户不用确认中间产物 |

## 视觉与动效

采用“奶油色像素小剧场”：背景 #FFF5E5，文字 #233D61，强调 #399AB2，金色 #D7A749，卡片 #FFFBF3，浅蓝 #DCEFF0，全部来自 app/main.lua。外部介绍排版使用本机微软雅黑，主标题 88–108 px，字幕 64 px，辅助 38–44 px。像素截图按 nearest-neighbor 整数倍放大，保持原生 240×240 像素风；不把它伪装成高分辨率设备录屏。

品牌已经由源码、角色与展示页确定，跳过独立 HTML 风格提案，先生成最终构图静帧作为 styleframe。只用平面构图与温和缓动，无震屏/闪屏/霓虹/假硬件外壳。标题主动作约 27 帧，稳态至少 30 帧。声音以角色台词为主，不加 BGM；这是对技能 S1 科技发布会鼓底和 Q8 强烈收尾的有意偏离，以适合慢半拍桌宠。新配音只做响度处理，不改音高或播放速度；各场景按完整台词时长自动延长，句后至少留 12 帧。

| # | 时间 | 画面与功能 | 主动作/字幕/音频 |

图库使用：仅 marker-underline-title，具体索引与准确 demo 另存 references/。其他镜头是原生小屏游戏的实际帧序列与非复刻介绍排版，自定义平面布局；不声称复刻某张卡。风险是原生小屏像素字在竖屏放大后显得粗糙，保留原像素并用大字号外部字幕解释关键变化。动作输入为离线脚本驱动，不代表本次 GUI 或硬件验收。

## 验证

每镜头三帧 still，自查手机宽度缩略图；成片抽样帧/接缝；ffprobe 检查分辨率帧率时长和声音，ffmpeg 验证解码、响度与逐句音轨相关性；本机 ASR 辅助检查台词，不把转写等同于主观音色听审。独立子代理依 final-review.md 检查，未实际主观听审的项目如实记录。
